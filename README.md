# TrackGrab
Windows desktop app to download tracks and albums from Yandex Music, SoundCloud, and Spotify. / Десктопное приложение для Windows для скачивания треков и альбомов с Яндекс.Музыки, SoundCloud и Spotify.

TrackGrab // v1.0

A Windows desktop application for downloading music tracks and full albums via links from popular streaming platforms.

FEATURES:
- Yandex Music: Full support. Download both individual tracks and complete albums.
- SoundCloud: Track downloading with parallel search (YouTube + SoundCloud) and automatic fallback to backup sources when encountering DRM protection.
- Spotify: Support for individual tracks.
- Tags & Cover Art: Automatic metadata tagging and album cover embedding.

KNOWN ISSUES & NOTES:
- Pasting links: Before pasting a link into the input field, make sure your keyboard layout is switched to English, then press Ctrl + V. Otherwise, the paste shortcut may not work.
- Spotify: Only single tracks are supported (no albums/playlists yet). Track matching can sometimes be inaccurate and download a different track with the same title.
- Language: The app interface is currently in Russian only.

HOW TO USE:
Run TrackGrab.exe, paste a link, choose a destination folder, and click "ЗАПУСТИТЬ ЗАГРУЗКУ".
TrackGrab // v1.0

Десктопное приложение для Windows, которое умеет скачивать треки и целые альбомы по ссылкам из популярных музыкальных сервисов.

ВОЗМОЖНОСТИ:
- Яндекс.Музыка: Полная поддержка. Можно скачивать как отдельные треки, так и целые альбомы со всеми композициями.
- SoundCloud: Загрузка треков с автоматическим параллельным поиском (YouTube + SoundCloud) и защитой от ошибок DRM (с переключением на резервные источники).
- Spotify: Поддержка отдельных треков.
- Теги и обложки: Автоматическое проставление метаданных и обложек для скачанных файлов.

ОСОБЕННОСТИ И ИЗВЕСТНЫЕ БАГИ:
- Вставка ссылки: Перед тем как вставить скопированную ссылку в поле ввода, убедитесь, что раскладка клавиатуры переключена на английский язык, иначе горячие клавиши могут не сработать. Для вставки используйте комбинацию Ctrl + V.
- Spotify: Поиск по Spotify поддерживает только отдельные треки. Иногда может возникать баг с неточным подбором: скачиваются треки с таким же названием, но не те, которые нужны.
- Интерфейс: Интерфейс приложения полностью на русском языке, переключателя языка нет.

КАК ПОЛЬЗОВАТЬСЯ:
Запустите TrackGrab.exe, вставьте ссылку, при необходимости укажите папку сохранения и нажмите «ЗАПУСТИТЬ ЗАГРУЗКУ».
